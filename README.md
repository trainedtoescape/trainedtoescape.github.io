# trainedtoescape.github.io

The public website for **Trained to Escape**, served by GitHub Pages at
<https://trainedtoescape.github.io/>.

Plain static files, no build step: `index.html`, `style.css`, `site.js`, and `media/`.
Screenshots and footage come from the game's own assets and screenshot renders.
Fonts (VT323, IBM Plex Mono) are under the SIL Open Font License; see `fonts/`.
